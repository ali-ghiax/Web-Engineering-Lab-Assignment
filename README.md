## About this project

A multi-page personal portfolio site customized from the FolioOne Bootstrap template. It includes:

- Home (hero, about, skills, stats, testimonials)
- Resume
- Services
- Portfolio (GitHub projects)
- Contact

## Tech stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (template vendors: AOS, Typed.js, Swiper, Isotope)

## How to open

Open `index.html` in a browser, or serve the folder locally:

```bash
npx serve .
```
