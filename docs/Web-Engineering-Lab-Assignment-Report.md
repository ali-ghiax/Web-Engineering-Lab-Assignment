## 1. Introduction

This report documents the design and development of a multi-page personal portfolio website completed as a **Web Engineering Lab Assignment**. The website presents the academic profile, professional skills, services, and software projects of **Muhammad Ali Ghias**, Junior Software Engineer, Graphic Designer, and Lead Microsoft Learn Student Ambassador at CUSIT.

The project applies core web engineering practices: structured HTML markup, cascading stylesheets, responsive layout, reusable Bootstrap components, and client-side JavaScript enhancements.

The FolioOne structure (header, sections, Bootstrap grid, vendor scripts) was kept. The following were personalized:

- Student name, roles, bio, education, and experience

- Social links (GitHub, LinkedIn, Instagram)

- Footer redesigned (professional layout, no Odoo / BootstrapMade credit line as requested during customization)  
- Profile photography (hero circular cutout; About cutout with accent neon underline)  
- Navigation simplified (Home, Resume, Services, Portfolio, Contact)
